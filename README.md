# neurolink  AI – Project Presentation

## Project Overview

**neurolink AI** is a futuristic AI-powered chatbot web application designed with a modern glassmorphism interface and smooth floating animations. The project delivers real-time conversational AI responses through the OpenRouter API while maintaining a clean and immersive user experience.

The application combines modern frontend design principles with conversational artificial intelligence to create an elegant and interactive chat platform.

# Features

## Core Features

### 1. Real-Time AI Chat

Users can interact with conversational AI instantly through the OpenRouter API.

### 2. Glassmorphism Interface

The UI uses blur effects, transparency, and modern card styling for a futuristic look.

### 3. Floating Background Animations

Animated floating circles create an immersive visual environment.

### 4. Responsive Design

The application adapts smoothly across desktop and mobile devices.

### 5. Smooth Chat Animations

Messages animate into the interface for a polished user experience.

### 6. Auto Scroll Messaging

The chat window automatically scrolls to the newest message.

### 7. Keyboard Interaction

Users can send messages using the Enter key.

### 8. API-Powered Intelligence

The chatbot connects to advanced conversational AI models through OpenRouter.

# System Architecture

```text
User Input
     ↓
Frontend Interface (HTML/CSS/JS)
     ↓
OpenRouter API Request
     ↓
AI Model Processing
     ↓
AI Response Returned
     ↓
Rendered in Chat Interface
```
